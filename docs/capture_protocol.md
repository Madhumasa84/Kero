# Capture Protocol



## Purpose



This protocol defines the minimum information and capture conditions required for

KeraScan test captures. It is intended to keep original images traceable and

preserved while avoiding collection of unnecessary personal information.



## Before Capture



Record:



\- Anonymous ID

\- Correct eye: OD (right) or OS (left)

\- Device version

\- Capture timestamp

\- Capture/session number where applicable

\- Operator identifier where required by the approved workflow



Do not record patient names or other directly identifying information in the

KeraScan test dataset.



## Capture Procedure



1\. Confirm the anonymous ID and correct eye.

2\. Confirm the device version.

3\. Ensure the eye is positioned and visible in accordance with the approved

&#x20;  device workflow.

4\. Acquire the image.

5\. Preserve the original file without modification.

6\. Record the required metadata.

7\. Record any visible capture problems.



Device-specific positioning, distance, illumination, exposure, or quality

threshold instructions remain \*\*pending device-team confirmation\*\* unless

already approved.



## Capture Problems to Record



Record visible issues such as:



\- Blur or motion

\- Glare or bright reflections

\- Obstruction or eyelid interference

\- Poor framing or off-centre positioning

\- Incomplete visibility

\- Other obvious acquisition problems



Do not replace an original image with a processed or corrected version.



## File and Metadata Requirements



Each approved capture should have:



\- Anonymous identifier

\- Correct eye designation (OD/OS)

\- Device version

\- Timestamp

\- Original image file

\- Capture/session information required by the approved workflow

\- Notes describing visible capture problems, if present



Original files must remain unchanged.



## Privacy and Storage



Do not commit patient-identifiable or clinical images to the repository.



Approved deidentified clinical captures must remain in the approved storage

location outside Git unless the project lead explicitly authorizes otherwise.



Synthetic test images must be clearly identified as synthetic and must not contain

invented patient or device information.



## Final Checklist



Before accepting a capture:



\- \[ ] Anonymous ID confirmed

\- \[ ] Correct eye confirmed

\- \[ ] Device version recorded

\- \[ ] Timestamp recorded

\- \[ ] Original file preserved

\- \[ ] Required metadata recorded

\- \[ ] Visible capture problems recorded

\- \[ ] No patient-identifying information included

\- \[ ] Any device-specific unapproved instructions marked as pending confirmation
